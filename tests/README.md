# Проверки Robbo Junior

```bash
scripts/build.sh
tests/run.sh
```

Нужны `xvfb` (`sudo apt install xvfb`) и свободный порт 9876: закройте Robbo Junior и Robbo Scratch. Запускается настоящий `desktop/main.js` на временном профиле, окном управляют настоящие события мыши. Реальный робот, панель, зеркала и проекты пользователя не затрагиваются.

| Что | Где |
|-----|-----|
| Строки всех языков и русские названия библиотеки (сверка с `media.json`) | `check-locales.js` |
| Время команд робота: конец блока, остановка, два скрипта | `robot-logic.js` |
| Сценарии в приложении: проекты, `.sjr`, робот на заглушке панели, «Что нового», справка, обновления | `smoke/scenarios.js` |

При провале снимки экрана лежат в `.build-logs/tests/`.

Проверить разложенное дерево вместо `desktop/`:

```bash
scripts/stage-app.sh linux /tmp/rj-stage
tests/run.sh --app /tmp/rj-stage/jr/resources/app
```

## Старый профиль

`fixtures/profile-0.0.23.tar.gz` создан настоящей программой: пакет `robbojunior0.0.23.deb` с `files.robbo.ru` запущен на временном профиле. В нём четыре проекта: 1 — скрипт из блоков робота, 2 — спрайт ROBBO, фон, текст и три страницы, 3 — нарисованный персонаж, 4 — записанный звук. `fixtures/project-0.0.23.sjr` выгружен оттуда же. Детских проектов в этих файлах нет. `fixtures/profile-0.0.23.home` — домашний каталог, где создан профиль: в базе лежат абсолютные пути, тест переписывает их в копии.

Каждый запуск `tests/run.sh` открывает этот профиль и проверяет содержимое. Профиль менять нельзя: это образец данных, которые лежат у пользователей.

Проверить копию реальной установки: скопируйте `~/.config/RobboJunior` и `~/.config/RobboJuniorProjects` в один каталог. Такие профили в репозиторий не кладём: в них проекты детей.

```bash
tests/run.sh --profile /путь/к/копии --old-home /home/имя
```

## На настоящем роботе

Заглушка панели не заменяет робота. Перед выпуском нужно закрыть Robbo Scratch, который держит порт, запустить Robbo Junior и убедиться, что индикатор стал зелёным, блок едет, а кнопка остановки обрывает длинный блок. При проверке 06.11.2026 движение было видно в третьей и четвёртой строках ответа `/txt/def/0/rob_check`.
