# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

Единственный источник версии RobboJunior. Верхний заголовок `## [X.Y.Z]` читает `scripts/sync-version.sh`
и переносит версию в приложение, пакеты deb/rpm, установщик Windows и Android.

Формат версии: `X.Y.Z`, `X.Y.Z-alpha` (предварительная), `X.Y.Z-N` (пересборка пакета той же версии).

## [1.0.0-alpha] - 06.11.2026

Первая сборка из монорепозитория. Код приложения тот же, что в 0.0.23: версия нужна, чтобы программа работала на современных системах.

### Добавлено

- **[Linux] Пакеты для новых систем:** deb для Debian, Ubuntu, Mint и Astra, rpm для Альта, РЕД ОС и Fedora. Прежний пакет зависел от библиотек, которых в новых системах нет.
- **[Windows] Новый установщик:** 64-битный установщик собирается на Linux. После установки программа запускается сама, галочку можно снять.
- **[All] Прошивка робота версии 11:** панель определяет такую прошивку и заливает её при обновлении. Раньше робот с версией 11 не определялся, а обновление заменяло её на версию 8.

### Изменено

- **[All] Сборка одной командой:** `scripts/release.sh` собирает все пакеты, Electron и Java скачиваются с проверкой sha256.
- **[All] Обновлён Electron:** версия 17.4.11. Java — Temurin 8u402.
- **[All] Проекты при обновлении:** проекты из 0.0.23 открываются в новой версии, удаление программы их не затрагивает.
- **[All] Панель и обновления:** панель больше не проверяет новые версии на сервере Robbo Scratch 2.
- **[Windows] Драйверы:** FTDI ставится всегда, Scratchduino/Arduino — по галочке для старых роботов. CH340 из установщика убран.

### Исправлено

- **[All] Определение робота:** панель ждёт 4 секунды вместо 2: при старте прошивка настраивает Bluetooth и отвечает примерно через 3 секунды.
- **[All] Меню окна:** убрано стандартное меню File, Edit, View с перезагрузкой страницы и инструментами разработчика.
- **[All] Работа с портами:** библиотека jSSC 2.6 заменена на 2.9.6, старая падала на 64-битной Java.
- **[All] Что вернули из 0.0.23:** прошивки, спрайты ROBBO, оформление пути к проектам в настройках и исключение порта `/dev/ttyS0`.
- **[Linux] Запуск на Ubuntu 22.04:** Java закреплена на 8u402, с 8u412 панель падает при старте на GNOME.
- **[Linux] Значки в доке:** у окон программы и панели теперь значок Robbo Junior.

Где изменено: `desktop/` (Electron 17, ветка `fs_backend-dev`), `packaging/common/panel/` (прошивки, `config.ini`, `beans.xml` в `i-robot.jar`), `packaging/linux/`, `packaging/windows/`, `scripts/`.

История версий до 1.0.0 — `docs/changelog-legacy.txt` (последняя — 0.0.18).
