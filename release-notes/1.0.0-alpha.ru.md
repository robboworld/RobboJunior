Программа снова работает на современных компьютерах.

### Новое

- **Новые системы:** пакеты для Debian, Ubuntu, Mint, Astra, Альта, РЕД ОС, Fedora и установщик для Windows 10 и 11.
- **Робот с прошивкой 11:** определяется и обновляется.

### Изменено

- **Проекты:** проекты из прошлой версии открываются, удаление программы их не затрагивает.
- **Драйверы Windows:** драйвер для старых роботов ставится отдельной галочкой.

### Исправлено

- **Поиск робота:** программа дольше ждёт ответа, поэтому находит робота надёжнее.
- **Спрайты ROBBO:** вернулись в библиотеку.
