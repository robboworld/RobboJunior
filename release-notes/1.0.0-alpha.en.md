The program runs on modern computers again.

### New

- **New systems:** packages for Debian, Ubuntu, Mint, Astra, Alt, RED OS, Fedora and an installer for Windows 10 and 11.
- **Robot firmware 11:** the robot is detected and can be updated.

### Changed

- **Projects:** projects from the previous version open, and removing the program keeps them.
- **Windows drivers:** the driver for older robots is a separate option in the installer.

### Fixed

- **Finding the robot:** the program waits longer for an answer, so it finds the robot more reliably.
- **ROBBO sprites:** they are back in the library.
