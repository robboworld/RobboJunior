# Сообщения о выпуске («Что нового»)

Пользователь видит их в окне «Что нового»: оно открывается нажатием на номер версии на главном экране. `CHANGELOG.md` остаётся журналом для разработчиков, здесь только то, что меняет работу пользователя, простыми словами.

Одна версия, которая идёт на сервер, — пара файлов: `<версия>.ru.md` и `<версия>.en.md`.

```markdown
---
version: 1.0.0
date: 06.11.2026
---

Короткий вводный абзац (необязательно).

### Новое

- **Предмет:** что изменилось.

### Изменено

- **[Important] Предмет:** что изменилось.

### Исправлено

- **Предмет:** что изменилось.
```

- Разделы RU: `Новое`, `Изменено`, `Исправлено`; EN: `New`, `Changed`, `Fixed`. Пустой раздел не пишем.
- В английском файле те же пункты в том же порядке.
- `[Important]` ставим только для потери данных, безопасности или обязательного действия: окно откроется при запуске само. На обычный выпуск новой версии программа показывает только точку.
- `date` можно оставить пустой до выпуска.

`scripts/build.sh` собирает файлы в `desktop/whats-new.json` и останавливается при ошибке формата. В сборку попадают версии не новее верхней в `CHANGELOG.md`, поэтому сообщение можно написать заранее. `scripts/deploy.sh` кладёт сообщение выкладываемой версии в `latest.json`, и окно обновления показывает его главные пункты.
