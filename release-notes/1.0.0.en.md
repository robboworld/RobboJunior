The stop button now stops the robot.

### New

- **Robot Stop block:** stops the robot at once.
- **"Robot not found":** the program tells you when the robot is not connected.
- **Update check:** the program tells you about a new version and offers to download it.
- **What's new:** this window. Click the version number on the home screen to open it, a red dot on it marks unread changes.
- **Robot block hints:** click a block in the palette to see what it does.

### Changed

- **Russian:** characters, backgrounds and sample projects have Russian names.

### Fixed

- **Stop button:** the robot stops at once instead of finishing the block.
- **Several robot scripts:** one script no longer stops the robot in the middle of another.
- **Starting scripts:** scripts without the robot start at once.
